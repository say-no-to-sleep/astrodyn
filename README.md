# A minimal and lightweight astrodynamics toolkit.

## Introduction

`astrodyn` is a from-scratch astrodynamics library built on NumPy/SciPy only. It is designed to be dependency-minimal and
portable.

## Modules

## Modules

| Module | Description |
|--------|-------------|
| `stumpff.py` | Stumpff C and S functions for universal variable methods |
| `states.py` | Container for orbital states scalar quantities derived from them |
| `elements.py` | Convert between State Vectors and Classical Orbit Elements |
| `frames.py` | Convert between different frames of references |
| `constants.py` | Contains useful constants |
| `propagate.py` | Propagates orbit using Kepler equations, and universal lagrange coefficients |
